# Identifying optical nonclassicality
Nonclassicality, defined via the Glauber-Sudarshan $P$ representation, is a fundamental resource for optical quantum devices as any nonclassical state creates entanglement at a beamsplitter.

This library provides you with the library to set up and train the algebraic classifier --- abbreviated wih **AlCla** --- that can be trained on a specifc dataset to learn a tailored nonclassicality criterion. Importantly, the criterion learned by the model may not be confused with a sufficient nonclassicality witness. Instead, the criterion is an indicator for whether a state in nonclassical or not.
