# Identifying optical nonclassicality
This library provides you with a variational model (the algebraic classifier, abbreviated wih **AlCla**) that can be trained on a specifc dataset to learn a tailored nonclassicality criterion. Nonclassicality, defined via the Glauber-Sudarshan $P$ representation, is a fundamental resource for optical quantum devices.

Importantly, the criterion learned by the model may not be confused with a sufficient nonclassicality witness. Instead, the criterion is an indicator for whether a state in nonclassical or not.
